# Даты и цитаты: проверка поведения

Два новых исполнителя `6.1 Sol / medium` применяют навыки к семи контролируемым случаям. Они получают исходники и формат наблюдений без ожидаемых решений. `metadata-results.json` содержит три ретроспективы; `quotation-results.json` — четыре аудита цитирования. Это выполнение навыков на тестовых материалах, а не повторный запуск описанных проектов.

```sh
python3 tests/evidence-provenance/check_results.py
```

Команда проверяет сохранённые наблюдения и хеши исходников. Она не запускает модель. После изменения навыков, критериев или фикстур нужно получить новые наблюдения для затронутых случаев.

Случаи различают неизвестную дату события, известную прошлую дату и противоречивые свидетельства. Проверка версии сохраняет подтверждённое значение и не подставляет неподтверждённое. Цитаты покрывают точный текст в другом разделе, изменение смысла, явно обозначенный пересказ и правильный текст с неверно указанным разделом. Дословные цитаты в ретроспективах сверяются с навыком.

Первоначальная дата была подставлена из даты сессии без свидетельства события. Первоначальная цитата, вопреки замечанию главного агента, была дословной: предложение находилось в другом разделе исходного навыка. Ошибку проверки подтвердил поиск полного исходника в коммите `2e6bd26`. Новый аудит должен различать отсутствие текста и неправильную ссылку на его место.

Материалы синтетические. Они не подтверждают реальные исторические запуски, расход токенов или стоимость. Один прогон не гарантирует соблюдение правил всеми моделями. Файлы фикстур должны оставаться неизменными; сохранение предложений требует отдельного одобрения.

Рекомендуемая модель для создания или изменения этих проверок: `6.1 Sol / medium`. Материалы не входят в устанавливаемые навыки.
