# Template skill routing observations

Eight prompt/oracle pairs cover one-word document edits, plan-only work, authority boundaries, read-only audits, graphics delegation, resume, narrow instruction audits, and completion retrospectives. Prompts are in `actor-inputs/`; matching criteria are isolated in `oracles/`. Send only the prompt files to fresh actors. Do not give actors the oracle files.

`results.json` records routing observations from two initial actors and a fresh `6.1 Sol / medium` confirmation of cases 1, 2, and 6. These are judgments about prompt routing and instruction selection. They do not record execution of the described document, code, graphics, audit, or tracker tasks. No task artifacts were supplied for cases 1 or 5, so completion of their requested edits cannot be scored. The observations do not measure token savings or establish statistical model performance.

Initial actor results remain separate from confirmation. The report preserves input gaps, conditional routing findings, and the actor protocol failure. It does not aggregate a pass percentage.
