# Логическая проверка навыка

`cases.json` содержит 34 синтетических случая и поведенческие ожидания. Они покрывают все 16 критериев. Есть положительные случаи, допустимые исключения и случаи с недостающими доказательствами. Фикстуры не содержат команд для выполнения и не требуют сети.

13 октября 2026 года отдельный проверяющий `gpt-6.1-sol / medium` применил навык к входным случаям. Он не получал диагностические названия и ожидаемые ответы. Результаты сохранены в `results.json`. Главный агент сопоставил наблюдения с ожиданиями и проверил причины замечаний.

Четыре исходных ожидания требовали нескольких меток одной причины. Их исправили по правилу «одно замечание на одну причину»: C05 — лишний текст; C07 — конфликт чтения; C11 — слишком широкий триггер; C33 — неподтверждённое заключение о доставке и исполнении инструкций. Это исправление эталонов, а не повторное выполнение случаев или исправление навыка.

Проверка сохранённых наблюдений:

```sh
python3 tests/agent-instructions-audit/check_results.py
```

Эта команда проверяет JSON наблюдений. Она не запускает модель и не выполняет новый аудит. После существенного изменения навыка получите новую независимую оценку: передайте проверяющему навык, справку и копию случаев без полей `title` и `expected`. Попросите вернуть JSON в формате `results.json`. Затем выполните:

```sh
python3 tests/agent-instructions-audit/check_results.py --results /absolute/path/to/new-results.json
```

Проверки установки и обновления из корневого README:

```sh
python3 tests/agent-instructions-audit/test_packaging.py -q
```

Шесть проверок используют временные каталоги. Они проверяют установку четырёх навыков, отказ при существующем каталоге или повреждённой символической ссылке, резервную копию до обновления и отказ до записи при отсутствии исходника. Копирование и `rsync` выполняются. Получение Git-обновления заменено локальной заглушкой; сеть и установленные навыки не затрагиваются. Используются стандартная библиотека Python, `sh` и установленный `rsync`. Новые библиотеки не устанавливаются.

Рекомендуемая модель для создания или изменения этих тестов: `6.1 Sol / medium`.

## Границы доказательств

Логические случаи проверяют решения и исключения по предоставленным данным. Они не доказывают поведение всех моделей, Markdown-обработчиков, операционных систем или сетевых сервисов. Проверка повреждённых ссылок здесь использует синтетические наблюдения. Реальные ссылки нужно разрешать средствами среды при конкретном аудите.

Один независимый прогон не является статистической оценкой точности. При новых дефектах добавляйте случай с наблюдаемым последствием. Не добавляйте ожидания, которые только повторяют текст навыка. Сохранённые результаты не измеряют токены, цену или экономию. Счётчики этого прогона недоступны.

Тестовые материалы остаются вне каталога навыка. Установка копирует только `skills/agent-instructions-audit`.
