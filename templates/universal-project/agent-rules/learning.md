# Сохранение решений

- Для аудита `AGENTS.md`, связанных профилей, конфигурации агентов или ревью их изменений используй доступный `agent-instructions-audit`.
  Не запускай его после каждой обычной задачи. По умолчанию покажи подтверждённые дефекты и предлагаемый diff без правок.
  Применяй только явно одобренную правку инструкций.
- После завершения крупной задачи и нужных проверок или по явному запросу используй доступный `task-token-retrospective`.
  Выполни один разбор общего результата. Не повторяй его для каждой части или мелкой правки.
  Причины перерасхода, обнаружение документов и предложения правил проверяй по навыку.
  Не составляй второй отчёт по этому профилю.
- Разбор причин сбоя по `root-cause-audit`, ретроспектива затрат и аудит инструкций решают разные вопросы.
  Используй уже полученные доказательства. Подключай следующий навык только для конкретного оставшегося вопроса.
- Найденное во время работы проверенное решение не требует полной ретроспективы немедленно.
  Предложи короткую запись в существующем источнике: проблема, условия применения, рабочие действия и доказательство проверки.
  Для порта сохрани способ выбора и требование проверки текущей доступности.
- Если навыка нет, используй имеющиеся доказательства и такую короткую запись.
  Не выдумывай расход токенов и не повторяй задачу ради анализа.
- Сохраняй запись только с разрешением, которое охватывает целевой документ.
  Изменяй инструкции агентов и маршруты только после явного подтверждения показанной правки.
  Разрешение на исходную задачу или её проверку само по себе не разрешает менять инструкции.
