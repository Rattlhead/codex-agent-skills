# Координация

- Для отдельного запроса о модели, бюджете или режиме выполнения используй доступный `task-model-router`.
- По умолчанию основной агент руководит работой: назначает исполнителей, следит за ходом и качеством, ставит дополнительные задания и принимает результат.
  Используй `subagent-manager` до полного исследования, кроме подтверждённого исключения для короткой самостоятельной цели целиком.
  Производственную работу и интеграцию выполняют исполнители. Связанную цепочку может выполнить один исполнитель; отдельный агент на каждый этап не нужен.
  Менеджер применяет обязательный `task-model-router`. Используй эту оценку, а не запускай вторую.
  Выполняй решение `primary_only` или `delegate` из текущей оценки.
- Назначение, владение ресурсами, переиспользование, сообщения и приёмку выполняй по менеджеру.
  Не создавай второй набор заданий и отчётов по этому профилю.
- Для неразрешённого нетривиального выбора в уже разрешённой длительной работе используй доступный `autonomous-decision-agent` через текущего менеджера.
  Маршрут выбора, условия назначения исполнителя и действия при его недоступности определяй по навыку.
  Обязательное согласие пользователя нельзя получить от другого агента. Решение не расширяет разрешения.
  Сохраняй текущий режим выполнения и единый журнал решений. Не создавай второй уровень управления.
- Не копируй процедуры, таблицы цен и алгоритмы навыков в правила проекта.
  Применение навыка не требует повторного чтения его актуального текста на каждом шаге.
- Если нужного навыка нет, укажи существенную недостающую зависимость.
  Продолжай только независимую разрешённую работу в границах выбранного режима и роли.
  Не запускай менеджер без роутера. Не заявляй точный бюджет или оптимальный подбор без данных.
  Если обязательное делегирование недоступно, останови зависимую работу и сообщи об ограничении.
- Личное выполнение — явное исключение: подтверди, что вся цель короткая и самостоятельная, способности основного агента достаточны, контекст ограничен и нет серии содержательных этапов или другого обязательного делегирования.
  Не применяй исключение к небольшому оставшемуся шагу уже делегированной цели. Неопределённость о размере всей цели не разрешает личное выполнение; действуй по менеджеру.
  Явный запрос модели, бюджета, менеджера или делегирования обрабатывай по соответствующему маршруту.
  Несколько действий внутри одной небольшой правки не требуют менеджера и роутера.
