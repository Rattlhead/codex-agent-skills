# Контекст, поиск и правки

- До чтения или поиска определи вопрос и минимальные данные для ответа.
  Используй известные пути, состояние и идентификаторы.
  Если среда поддерживает поиск инструментов, запрашивай описания для нужной операции. Полный каталог читай только для обоснованного выбора.
- Для файлового поиска начни с известного пути. При наличии `rg` используй `rg --files -g` для имён и `rg -n` в выбранных файлах.
  Для буквального текста используй `rg -F`, для имён совпавших файлов — `rg -l`.
  Для другой среды используй доступный поиск с теми же ограничениями. Не устанавливай инструмент ради одного поиска.
  Используй регулярное выражение для формы совпадения.
- Ограничивай пути, поля, длину значений и контекст вывода.
  Для длинных строк, минифицированных файлов и таблиц извлекай нужные поля или короткие фрагменты.
  Лимит совпадений на файл не ограничивает общий вывод поиска.
- Для точного подсчёта, сравнения и фильтрации используй подходящий существующий инструмент.
  Обрабатывай большой набор в доступной среде инструмента. В контекст возвращай итог и нужные доказательства, а не все промежуточные данные.
- Объединяй необходимые независимые чтения и запросы, если инструмент это поддерживает.
  Сохраняй отдельные результаты и ошибки. Зависимые действия и изменения выполняй в нужном порядке.
  Не расширяй область данных ради объединения запросов.
- Расширяй поиск только для конкретного пробела. Остановись, когда вопрос решён.
  После обрезанного вывода запрашивай недостающие факты, а не тот же полный вывод.
- Не читай тяжёлые каталоги и полные журналы без причины.
  Читай нужную часть lockfile или generated-файла, если вопрос зависит от неё.
- Перед правкой прочитай текущий блок целиком и существенные зависимости.
  Сделай точный минимальный патч. Сохрани чужие правки и формат.
  После правки просмотри diff или доступное сравнение версий артефакта.
- Для автоматической замены заранее установи область и ожидаемые совпадения.
  Для вложенной структуры используй парсер или точный патч.
  Останови замену при расхождении ожиданий.
- Повторяй чтение при изменении источника, устаревших данных или конкретном пробеле.
  Не дублируй историю, полные файлы и успешные журналы в сообщениях.
- Пиши коротко и точно. Сохраняй требования, ошибки и существенную неопределённость.
  Применяй принципы ясного технического языка. Не заявляй соответствие ASD-STE100 без проверки английского текста по стандарту.
