# Маршрут работы

Для новой задачи прочитай `agent-rules/task-and-contract.md` и
`agent-rules/context.md`. Применяй их к дальнейшим действиям.
Повторно читай неизменённые правила только для устранения конкретного пробела.

Остальные файлы прочитай при выполнении условия в таблице.
Сначала используй существующие маршруты и правила затронутой области.
Если ссылка отсутствует или устарела, сообщи о пробеле и найди нужный источник.

| Условие | Правила |
| --- | --- |
| Запуск команд, работа с зависимостями или средой | [Среда](agent-rules/environment.md) |
| Изменение программного поведения | [Разработка](agent-rules/software.md) |
| Документы, исследования, данные или графика | [Артефакты](agent-rules/artifacts.md) |
| Проверка или приёмка результата | [Проверки](agent-rules/verification.md) |
| Выбор исполнителя, делегирование или работа нескольких агентов | [Координация](agent-rules/coordination.md) |
| Завершение крупной задачи или найденное решение повторяемой проблемы | [Сохранение решений](agent-rules/learning.md) |
